## How to write a new article

Every article lives in its own folder under `src/pages/articles`. To create a
new post:

1. Copy this folder (`hello-world`) and give the copy a short, URL-friendly
   name — that name becomes the address of the post.
2. Edit the `meta` block at the top of `index.mdx` with your title, the date,
   and a one-sentence description.
3. Write your article below it in
   [Markdown](https://www.markdownguide.org/basic-syntax/).

Markdown is mostly just plain text. You can make text **bold** or *italic*,
add [links](https://example.com), and create lists like the one above.

## Adding images

Drop an image file into the article's folder and reference it like this:

```
![A caption for the image](./photo.jpg)
```

That's it — once you push your changes, the site rebuilds and publishes
automatically. Happy writing!
